# Сайтът на BurroSped

Статичен сайт (HTML + CSS, без build). Netlify: Publish directory = `.` (коренът), без build команда.

## Готово
- `vashite-danni/` – „Данните са ваши“ (BG), пренесена от дизайна с поправени текстове:
  - махнат собственият сървър (бутонът в началото, картата и целият раздел);
  - махнати „никой… дори ние“, „Дори ние не можем да надникнем“, „Заключени, дори за нас“,
    „никой от Спедитор не може да отвори данните ви“ → вместо тях: поддръжката е изключена, докато не я разрешите.
- `site.css` – общите стилове от дизайна.

## Остава
- Начална страница (BG) и двете страници на EN и DE.
- Декоративните линии от дизайна не са пренесени (тежки SVG); добавят се отделно, ако ги искаш.
- Име: в дизайна още пише „Спедитор“ – смяна на BurroSped след отговора на адвоката за марката.
- Линковете „Вход“, „Пробвайте безплатно“, правните страници и „Пишете ни“ са `#`.
- `[ДОСТАВЧИК]` във футъра – името на фирмата, след решението от коя фирма се продава.

## Проверка преди публикуване (текстът трябва да е верен)
- „Нощни бекъпи, криптирани с AES-256, пазят се 90 дни“ и „криптирани нощни бекъпи“ – верни са само след като
  нощният бекъп в GitHub работи (сега пада).
- „Споразумение по GDPR“ – след прегледа на адвоката.
- „до 30 дни след отказ“ – да съвпада с общите условия.
